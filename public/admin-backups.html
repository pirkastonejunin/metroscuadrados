Copias de seguridad de la base

Cada noche (entre las 3 y las 7 de la mañana) el sistema exporta toda la base, la comprime, la cifra y la sube a Cloudinary (carpeta backups-sistema). Se guardan las últimas 14 copias.

Cómo se recupera una copia

Las partes de una copia se bajan de Cloudinary y se restauran en una base nueva con restaurarCopia.js (nunca pisa la base en uso). Pedime ayuda cuando haga falta. Guardá la clave BACKUP_CLAVE también fuera de Render (por ejemplo en tu gestor de contraseñas): sin ella las copias no se pueden abrir.
