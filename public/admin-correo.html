Correo automático a clientes

Cuando se emite una venta, nota de crédito o nota de débito, o se registra un cobro o una cobranza, el sistema le manda un mail al cliente que tenga correo cargado, con el link para ver el comprobante o el recibo. Las facturas fiscales salen recién cuando ARCA les da el CAE. Un cliente se puede excluir desde su ficha ("No enviarle mails automáticos").
